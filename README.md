# YPF Ruta Contado

App Android offline para ingresar los precios de surtidor de Infinia Diesel y Diesel 500, calcular automáticamente los descuentos (8%, 4% y 2%), generar la imagen promocional y compartirla por WhatsApp.

- Infinia Diesel · Tarjeta Roja Batán: 8%
- Diesel 500 · Tarjeta Roja Batán: 4%
- App YPF Ruta: 2% para ambos
- Resultado siempre con 2 decimales
- Fecha automática
- Funciona sin internet
